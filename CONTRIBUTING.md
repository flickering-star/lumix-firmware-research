# Archive policy

This repository is an unmaintained research reference. It is not accepting
contributions, pull requests, bug reports, feature requests or support requests.
There is no commitment to review submissions, answer questions, test another
camera model or maintain compatibility with future software or firmware.

Use your own fork for experiments, corrections and extensions. The reproduction
and model-porting guides document the tested results and the boundaries of the
available evidence so independent work can proceed without maintainer support.
